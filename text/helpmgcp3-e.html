王族魔法：特殊
灼熱武器：

學習等級：40級

類型：賦予

屬性：正義

魔力／體力：25 / 0

期間：1200秒

對象：畫面內的隊伍與血盟成員

效果：持續時間內近距離與弓的命中+5、魔法防禦+20。灼熱武器與閃亮之盾會互相取代：施放其中一種會移除另一種。勇猛意志可與任一種並存。

援護盟友：

學習等級：45級

類型：賦予

屬性：中立

魔力／體力：30 / 0

期間：瞬間

對象：所指定的1名同血盟玩家

效果：可傳送到血盟成員當前所在位置，但無法傳送到地監或無法記憶座標的地方。

勇猛意志：

學習等級：50級

類型：賦予

屬性：正義

魔力／體力：25 / 0

期間：1200秒

對象：畫面內的隊伍與血盟成員

效果：持續時間內近距離攻擊傷害+5。可與灼熱武器或閃亮之盾並存。

閃亮之盾：

學習等級：55級

類型：賦予

屬性：正義

魔力／體力：25 / 0

期間：1200秒

對象：畫面內的隊伍與血盟成員

效果：持續時間內防禦力提升8點。閃亮之盾與灼熱武器會互相取代：施放其中一種會移除另一種。勇猛意志可與任一種並存。

神聖犧牲：

學習等級：60級（經典版50級）

類型：治癒

屬性：正義

魔力／體力：50 / 30

期間：瞬間

對象：畫面內的血盟成員（不含施法者）

效果：為畫面內的血盟成員恢復一般治癒3倍的體力，以滿血復活畫面內倒下的隊伍或血盟成員，並復活施法者倒下的寵物。復活他人後，施法者會跪地祈禱，8秒內無法移動。

王者加護：

學習等級：60級（經典版50級）

類型：賦予

屬性：中立

魔力／體力：30 / 0

期間：128秒

對象：畫面內的隊伍成員

效果：畫面內每有1名隊伍成員，每位成員魔法防禦+2，另外昏迷耐性+2、最大體力+50、最大魔力+25。施法者同時獲得屬性之火，施法者與附近的隊伍成員有機會獲得一次性、持續16秒的鏡反射。
