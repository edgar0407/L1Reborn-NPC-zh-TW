# 天堂 Reborn NPC 對話繁中化 (v1.0)

> **使用者文件**：NPC 對話檔下載與使用說明
>
> 這是給 GitHub 使用者看的說明文件。專案內部的翻譯規則、修正紀錄、協作筆記另外維護，不放在這個 repo 裡。

天堂（Lineage）Reborn 私服 NPC 對話檔的繁體中文翻譯補完專案。
修正原版 `-c.html` 大量亂碼問題，讓 Reborn 伺服器的 NPC 對話正確顯示繁體中文。

---

## 快速開始：我該下載哪個資料夾？

本專案有兩個資料夾，依你的情況選一個：

| 你的狀況 | 該下載 | 說明 |
|---|---|---|
| **第一次安裝**，或很久沒更新 | [`text/`](./text) | 完整、隨時可直接覆蓋進遊戲的全部檔案 |
| **已經有舊版**，只想補上最近的更新 | [`Recent/`](./Recent) | 只有最近改過的檔案，檔案數量少很多，抓下來直接覆蓋對應檔名就好 |

`Recent/` 裡的 [`CHANGELOG.md`](./Recent/CHANGELOG.md) 會列出最近改了哪些檔案、做了什麼，可以先看那份說明再決定要不要更新。

### 下載單一資料夾（不用整個 repo）

GitHub 網頁上，進到 `text/` 或 `Recent/` 資料夾頁面，點右上角「**...**」（更多選項）→「**Download directory**」，就會下載該資料夾打包好的 zip，不用整個 repo 一起抓。

> 如果你的 GitHub 介面沒有這個選項（帳號/瀏覽器版本較舊），可以改用：
> - 整包 clone：`git clone https://github.com/edgar0407/L1Reborn-NPC-zh-TW.git`，再自己進 `trunk/text/` 或 `trunk/Recent/` 拿需要的部分
> - 或搜尋「GitHub 下載單一資料夾」相關的第三方小工具

### 套用至遊戲

把下載到的 HTML 檔案透過伺服器打包工具（pack）覆蓋進遊戲的 NPC 對話資料夾，
重新啟動伺服器後即可看到繁體中文 NPC 對話。

## 專案背景

Reborn 伺服器的遊玩環境以英文為主（`-e.html`），
原本的繁中對話檔（`-c.html`）存在大量亂碼，推估為 ANSI 意外轉成 UTF-8 的問題。

本專案的修正流程：
1. 以 Reborn `-e.html`（英文版）為最終內容權威
2. 若 Real 繁中客戶端的 `-c.html` 連結結構與 Reborn 相符，直接套用
3. 結構不符時，從英文版翻譯並標記 `<!-- 烏薩奇: AI英翻中 -->` 供人工複審

## 目錄結構

```
trunk/
├── text/              ← 完整版，所有 NPC 對話檔（隨時可直接覆蓋進遊戲）
├── Recent/            ← 近期更新的檔案（只是 text/ 同名檔案的副本，方便瀏覽/單獨下載最新變動）
│   └── CHANGELOG.md   ← 近期更新的文字說明
├── Customization/     ← 自訂內容
└── README.md          ← 本文件
```

> ⚠️ `Recent/` 只是「最近改了什麼」的唯讀副本，**不是**獨立完整可用的一份，記得它底下的檔案要拿去覆蓋你原本已經裝好的 `text/` 內容，而不是單獨拿 `Recent/` 去跑遊戲。

## 檔案說明

本專案輸出的檔案都是 `npcname-e.html` 這種檔名（`-e` 結尾）。

`-e` 原本是 Reborn 伺服器給「英文版」對話檔用的命名慣例，但因為伺服器實際讀取、打包進遊戲的就是這個檔名，所以本專案直接借用 `-e.html` 這個檔名來放繁體中文翻譯內容——**檔名是 `-e`，但打開來看到的是中文**，這是正常的，不是放錯檔案。

> ⚠️ 所有 HTML/TBL 檔案使用 **ANSI 編碼**，請勿以 UTF-8 重新儲存，否則會產生亂碼。

## 貢獻方式

歡迎協助人工複審 AI 翻譯的對話檔。
由 AI 從英文翻譯的檔案，開頭會有以下標記：

```html
<!-- 烏薩奇: AI英翻中 -->
```

標記代表該檔案尚待人工複審，歡迎提交修正的 Pull Request。
